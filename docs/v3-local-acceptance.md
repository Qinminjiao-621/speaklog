## 5. JSON 与安全机制

英文继续接受 schemaVersion: 1 的单篇、数组、notes 容器与历史兼容字段。中文为 schemaVersion: 2，字段 id/day/date/title/content，支持单篇或数组，正文原文保存；示例见 README 和应用新增页。

版本明确分离：英文 schema 1、中文 schema 2、应用 dataVersion 3、全量 backupVersion 3、IndexedDB version 1。V1/V2/V3 恢复均需预览确认；拒绝跨本身份、语言与编号歧义。

Markdown 使用 react-markdown 10 + remark-breaks，无 raw HTML 插件、无 dangerouslySetInnerHTML。标签白名单，HTML 忽略，链接仅文字，图片和 iframe 不生成元素或网络请求。脚本、事件处理属性、javascript/data 链接、SVG、iframe 及远程图片攻击用例通过。参考 [react-markdown 安全说明](https://github.com/remarkjs/react-markdown#security)。
